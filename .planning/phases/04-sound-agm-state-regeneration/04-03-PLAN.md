# Plan 04-03: AGM Recovery Regression Tests

<objective>
Add generated-module regression tests proving that AGM recovery only succeeds for deterministic singleton recovery and withholds for ambiguous, impossible, and symbolic cases.
</objective>

<tasks>

1. **Create generated AGM recovery EUnit module**
   - File: `detecter/test/regeneration/generated_agm_recovery_test.erl`
   - Generate monitor modules into temporary directories using `maxhml_eval:compile/2`.
   - Compile generated modules with `export_all` for tests so unexported generated AGM helpers can be called directly.
   - Clean up temp directories recursively.

2. **Test unique concrete recovery**
   - Use the token-system spec where `LastKnownState = s1`, missing event is `0`, next observed event is a concrete value accepted from `s2`.
   - Seed `sus_state` with the last known state.
   - Send the expected next trace event to the test process mailbox before calling generated `handle_missing_event/1`.
   - Assert `{ok, Recovery}` and assert the recovered event descriptor is literal `0`.

3. **Test ambiguous state recovery**
   - Use a temporary system-info spec where the intersection for `S_X0` has multiple states.
   - Assert `{withhold, ambiguous_state}` or the agreed equivalent reason.

4. **Test ambiguous event recovery**
   - Use a temporary system-info spec with duplicate `Src -> Dst` rows carrying different literal events.
   - Assert `{withhold, ambiguous_event}`.

5. **Test impossible recovery**
   - Use a temporary system-info spec or current-state/next-event combination where no compatible `S_X0` exists.
   - Assert `{withhold, impossible_recovery}`.

6. **Test symbolic recovery**
   - Use a case where the only missing event candidate is a symbolic/ranged descriptor, such as `N` or `Z \ 0`.
   - Assert `{withhold, symbolic_event}`.

7. **Wire test into default target**
   - File: `detecter/Makefile`
   - Add `generated_agm_recovery_test` to `make test` after `generated_monitor_smoke_test`.

</tasks>
